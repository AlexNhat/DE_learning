# 📂 Cấu trúc thư mục dự án Data Engineering

docker: dockerfile for build image, which would be called from docker_compose.yml
docs: contains java's src doc and python's src doc
misc: for figure(s), nontrivial stuff
notebooks: Jupyter notebook

raw_data: not preprocessed data
sandbox -> move to src/<lang>

src/main: contains stable and sandbox code for both java and python
src/main: contains stable and sandbox code for both java and python
src/resources: shared used resources by both java and python. For instance, db config, css, etc

src/test: contains coresponding test code of src

target: java's compiled code (generated by Intellij)
.env: environment variable used in docker-compose.yml
pom.xml: java build tool config
uv: python build tool config
